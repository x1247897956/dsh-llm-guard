# 合成安全评测集

`heldout.jsonl` 是本仓库 v2 新增的合成文本集，替代旧评测数据。每行包含
`id`、`text`、`label`、`category`、`note`；label=1 表示风险，label=0 表示正常。
恶意标签包含提示词注入、越狱、敏感数据；正常样本按对应风险类别分桶。

## 构造与范围

按类别和正负标签构造样本，覆盖字面指令、间接泄露、角色扮演、心理暗示、
长文本包裹、编码、零宽字符、拆分和藏头。正常文本包括“忽略”一词的业务用法、
合法角色扮演、术语讨论，以及含邮箱和手机号占位值的业务文本。
`note` 记录考点；不包含可操作的真实攻击教程或公司内部材料。

邮箱使用 example.com；手机号、身份证样式数字和凭据均按合成占位文本处理，
不来自真实个人资料。数字形似有效号码并不证明属于保留测试号段，不应联系或验证这些号码。
凭据为 TESTONLY/EXAMPLE 占位值或公开示例，不能用于实际登录。

## 标注来源与局限

文件中的标签随合成样本提供；历史构造过程没有可审计的逐条作者记录，不能断言全部由人手写。
本次用户确认“人工复核全通过”，按全量标签接受记录；没有逐条签名复核表，因此该确认
不是独立第三方审计。机器评测直接比较检测结果与这些固定标签，没有另用 LLM 裁判打分。

文件名沿用 heldout，但已经反复用于评测，未建立独立 dev/test 划分，不应称为未见测试集。
样本分布由构造意图决定；存在边界标签、近重复、单轮文本与中英覆盖局限。
不能据此推断真实流量效果。数据按仓库 MIT 许可提供。
